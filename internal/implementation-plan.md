# 图文开发指南实施安排

目标：以 VitePress 发布可连续学习、按需查阅的通用 AI 辅助开发教材，Markdown 为内容源。

已确认：12章主线，活动报名与审核系统贯穿案例；人类沟通角色用甲方与“你”；所有提示词逐处标示仅作为示例，不建议作为实际项目中的提示词使用；不做账号、学习进度记录；配图采用数字教材式情境讲解。

- [ ] 补写01、02章，统一示例项目与规则来源。
- [ ] 并行完成04—07章、08—12章，审阅跨章一致性。
- [ ] 建立提示词、检查清单、案例记录三个查阅入口。
- [ ] 配置VitePress目录、本地搜索、移动阅读和打印样式。
- [ ] 制作场景化教学图，检查其与正文的语义一致性。
- [ ] 自动检查Markdown链接、示例标记、禁用场景词、构建。
- [ ] 浏览器检查首页和章节的桌面、窄屏效果。

视觉：暖白纸张、墨绿标题、橙色步骤编号。正文优先清楚、段落短、图中少字且有文本等价解释。保留深色模式。无外部字体、统计或账号依赖。

验证：静态检查脚本、生产构建、浏览器实看。不为文档编写镜像实现式单元测试。依赖与版本锁定在包管理文件。无远端发布操作。
